# MSc in Artificial Intelligence & Deep Learning — Applied Projects Archive

A centralized repository containing applied machine learning pipelines, deep neural architectures, real-time computer vision systems, and comprehensive technical reports.

All projects were developed as part of the **MSc in Artificial Intelligence and Deep Learning** at the **University of West Attica (UNIWA)**, an advanced postgraduate program **powered by the NVIDIA Deep Learning Institute (DLI)**.

---

### 🎓 Academic Context
- **Institution:** University of West Attica (UNIWA), Athens, Greece
- **Program:** Master of Science (MSc) in Artificial Intelligence and Deep Learning
- **Industry Partner:** Powered by NVIDIA Deep Learning Institute (DLI)
- **Focus Areas:** Supervised Machine Learning, Deep Neural Networks, Real-Time Computer Vision, Feature Engineering, Econometric & Risk Modeling.
